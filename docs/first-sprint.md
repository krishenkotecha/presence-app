# First Sprint

## Sprint Goal

Ship a tappable `Presence` prototype that makes the product concept feel real before any live analysis work begins.

## Tasks

1. Install full Xcode on the Mac if it is not already installed.
2. Create or regenerate the SwiftUI app project named `Presence`.
3. Build the home, setup, recording, check-in, and reflection flow.
4. Seed the app with believable example conversations and reflections.
5. Make the product language feel coherent end to end.
6. Validate the prototype builds locally.

## Suggested App Modules

- `App`
- `Features/Setup`
- `Features/CheckIn`
- `Features/Recording`
- `Features/Results`
- `Core/Scenarios`
- `Core/Models`
- `Core/Storage`

## First Decision Rules

If the setup feels like a form, simplify it before adding more categories.

If the reflection feels generic, improve seeded scenarios and copy before building analysis logic.

## Immediate Next Step

Create the iOS app shell and make the coached conversation loop tappable from end to end.
